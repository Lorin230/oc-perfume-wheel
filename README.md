# OC 调香轮盘

一个使用 HTML、CSS、Vanilla JavaScript 与 SVG 制作的纯静态调香轮盘。

页面通过三个可独立旋转的同心圆环，从前调、中调和后调词库中随机抽取一组香气结果。项目不需要构建工具、npm 依赖或后端服务，可以直接在浏览器中运行。

## 功能

- 最外圈：160 个后调扇区
- 中间圈：120 个中调扇区
- 最内圈：100 个前调扇区
- 共生成 380 个独立 SVG `path`
- 380 个香料名称与 ID 均不重复
- 三层圆环独立旋转并精确停靠至顶部指针
- 旋转结束后显示前调、中调和后调结果
- 支持桌面端、手机端与减少动态效果模式
- 宣纸质感的纯 CSS 页面背景

## 技术栈

- HTML
- CSS
- Vanilla JavaScript
- SVG

项目未使用 React、Vue、Next.js、Canvas、CSS 框架、npm 包或后端服务。

## 文件结构

```text
.
├── index.html              # 页面语义结构
├── styles.css              # 页面视觉与响应式布局
├── data.js                 # 100 / 120 / 160 条香料数据
├── app.js                  # SVG 扇区生成、随机抽取与旋转逻辑
├── tests/
│   └── verify-wheel.js     # 轮盘结构、数据与交互测试
└── docs/                   # 设计与开发计划文档
```

## 本地运行

直接双击 `index.html`，或将项目目录作为任意静态网站目录打开即可。

页面不使用本地 `fetch`、模块打包或服务器端逻辑，因此可以通过 `file://` 直接运行。

## 测试

需要安装 Node.js，然后在项目目录执行：

```bash
node --test tests/verify-wheel.js
node --check data.js
node --check app.js
```

测试覆盖：

- 三组香料数量与全局唯一性
- 380 个独立 SVG 扇区的实际生成数量
- 三层圆环半径与顺序
- 固定指针位置
- 随机抽取、按钮锁定与结果显示
- 三圈独立旋转及精确停靠
- 减少动态效果模式

## 部署

这是纯静态项目，不需要构建命令。部署到 Netlify 等静态托管服务时，将项目根目录设置为发布目录即可。

## 当前范围

项目目前只包含调香轮盘、香料数据、随机抽取、旋转停靠与结果显示，不包含 AI、登录、数据库、保存图片或分享功能。
