# OC 调香轮盘第一阶段设计

## 目标

交付一个可直接双击 `index.html` 运行的纯静态单页网页。页面包含三层同心 SVG 轮盘、固定指针、圆心“开始”按钮与“香气结果”占位卡片，但不包含随机、旋转、揭晓、AI、数据库或后端功能。

## 文件职责

- `index.html`：页面语义结构、三个互相独立的 SVG group、固定指针、圆心按钮和结果卡片。
- `styles.css`：暖白宣纸氛围的纯 CSS 近似、三层轮盘周边布局和手机响应式。
- `data.js`：仅保存用户指定的 OC 香调词库：100 个前调、120 个中调、160 个后调。允许同一名称按用户清单出现在不同香调层级，不擅自替换、补充或重新分类。
- `app.js`：环形扇区几何函数、三个 SVG group 的动态绘制和实际 DOM 数量校验。
- `tests/verify-wheel.js`：使用 Node 内置模块执行数据与绘制脚本，验证真实数据、环层顺序及 380 个独立 SVG path。

## 几何结构

SVG 使用 `viewBox="0 0 720 720"`，圆心为 `(360, 360)`：

- 后调：内半径 250，外半径 340，共 160 个扇区。
- 中调：内半径 165，外半径 245，共 120 个扇区。
- 前调：内半径 80，外半径 160，共 100 个扇区。
- 圆心按钮视觉直径约 120，按钮与前调内缘之间留白。

每个扇区是一个独立 `<path class="segment">`。扇区角度由 `360 / notes.length` 得到，绘制逻辑不硬编码每圈条目数量。

## 数据边界

数据以用户提供的三组 OC 香调名单为唯一来源，不再采用先前整理的其他词库。保留用户清单中的自然意象与氛围词，例如“雨后空气”“森林空气”；不使用编号占位名称。每条数据只包含稳定 `id` 与中文 `name`，绘制逻辑仅按数组长度生成扇区。

## 视觉与交互边界

- 背景仅使用 CSS 颜色和多层低对比度渐变近似暖白宣纸，不使用背景图片。
- 后调为米色/奶油色，中调为淡紫/粉紫色，前调为淡粉/桃色。
- 固定指针位于 12 点方向，尖端朝向外圈，不属于任何 ring group。
- 380 个名称不显示在轮盘上。
- “开始”按钮为静态结构，本阶段不绑定业务行为。
- 桌面和手机端均不得裁切轮盘或指针。

## 验收

实际 DOM 中 `#base-ring path.segment`、`#middle-ring path.segment`、`#top-ring path.segment` 数量必须分别为 160、120、100，总计 380。Console 输出相应数量且无异常。页面双击打开可运行，无网络、包管理器或构建步骤。
